# Work Log - 2026-02-05

## Summary of Changes

### 1. Centralized Data Generation with Faker Integration
- **Refactored Generators**: Updated `DocumentDataGenerator`, `KIEDataGenerator`, `MarkdownDataGenerator`, and `TableDataGenerator` to use a new centralized `DataProvider`.
- **DataProvider Implementation**: Created `src/generator/data_provider.py` to provide a unified interface for language-specific data generation, reducing code duplication across generators.
- **Faker Integration**: Added `faker` as a dependency to generate realistic synthetic data for multiple languages (initially supporting Korean, English, Japanese, and Hindi).
- **Seed Support**: Added `--seed` argument support to ensure reproducible data generation.

### 2. Script Reorganization and Corpus Support
- **Directory Restructuring**: Reorganized the `scripts/` directory into logical subdirectories:
  - `scripts/corpus/`: For external corpus generation.
  - `scripts/dataset/`: For dataset generation and evaluation.
  - `scripts/models/`: For model execution and testing.
- **External Corpus Generation**: Added `scripts/corpus/generate.py` to support large-scale corpus generation from external sources.
- **Tiered Data Loading**: Updated `DataProvider` to support tiered data sources (External Corpus > Faker > Hardcoded fallbacks).

### 3. Documentation Updates
- Updated all documentation files (`cli.md`, `evaluation.md`, `overview.md`) to reflect the new script paths and features.
- Added `docs/generation.md` with detailed instructions for external corpus generation.
- Added documentation for the new `--seed` argument in `docs/cli.md`.

### 4. Language Script Improvements
- Updated 65 language-specific generation scripts in `scripts/dataset/lang/` with improved formatting and relative path handling.
